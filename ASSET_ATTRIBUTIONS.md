| Asset | Official source |
| --- | --- |
| `frontend/public/editors/vscode.svg` | [Visual Studio Code brand resources](https://code.visualstudio.com/brand), `visual-studio-code-icons/vscode.svg` in the official icon archive |
| `frontend/public/editors/phpstorm.svg` | [JetBrains brand resources](https://www.jetbrains.com/company/brand/), [PhpStorm SVG](https://resources.jetbrains.com/storage/logos/web/phpstorm/phpstorm.svg) |
| `frontend/public/editors/zed.png` | [Zed brand resources](https://zed.dev/brand), stable application icon |
| `frontend/public/integrations/jira.svg` | [Atlassian logo library](https://atlassian.design/resources/logo-library), original Jira icon |

Visual Studio Code, PhpStorm, Zed, GitHub, and Jira names and marks belong to their respective owners. Their appearance identifies supported editors or integrations and does not imply endorsement of M.I.E.R.
